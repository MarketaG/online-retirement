# Online Retirement

Modern React frontend built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

The project focuses on clean component architecture, accessibility, and a user-friendly learning experience for seniors.

---

## Tech Stack

- ⚛️ React
- 🟦 TypeScript
- ⚡ Vite
- 🎨 Tailwind CSS
- 🎯 Lucide Icons

---

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/MarketaG/online-retirement.git
cd online-retirement
npm install
```

---

## Running the Project (Development)

```bash
npm run dev
```
